## [Unreleased]

Запланированные изменения для версии **2.1.0** — на основе результатов тестирования
версии 2.0.0 и отзывов пользователя.

### Планируется добавить
- Кнопка «Тестовые данные» в окне настройки VPN для автозаполнения полей.
- Горизонтальное расположение блоков VPN-Клиент и VPN-Сервер в окне настройки VPN
  (вместо текущего вертикального).
- Проверка совпадения VPN-протокола на клиенте и сервере перед установлением туннеля
  (сейчас соединение устанавливается даже при разных протоколах).
- Полная переинтеграция паспорта безопасности с базой уязвимостей
  [NVD NIST](https://nvd.nist.gov/vuln/search#/nvd/home?resultType=records):
  новый скрипт извлечения CVE с качественной сортировкой компонентов, чтобы
  компоненты не путались и не создавались «из воздуха».
- Изолированный режим редактирования размера зоны: при активации блокируются
  остальные элементы интерфейса, появляются кнопки «Сохранить»/«Отмена».
- Полный редизайн таблицы маршрутизации (визуально, структурно и по содержимому
  окна создания правила) — на основе принципов реальных IP routing tables.

### Планируется изменить
- Убрать красную пунктирную обводку вокруг иконок узлов при однократном нажатии.
- Синюю пунктирную обводку (при перетаскивании) сделать сплошной.
- Вкладка «Сеть» во всех окнах — унификация стиля фреймов (единый фон + выделение
  параметров в минималистичные рамки, аналогично тому, как это сделано в окне VPN).
- В окне «Настройка межсетевого экрана» укоротить зелёную обводку статуса:
  она должна охватывать только надпись «Состояние: включен/выключен», а не всю
  строку целиком.
- В окне «Создание правила» межсетевого экрана — унифицировать разнотонность фреймов.

### Планируется удалить
- Кнопка экспорта паспорта безопасности в CSV (остаётся только PDF-экспорт).

### Планируется исправить
- Матрица сетевой связности: корректный учёт правил межсетевого экрана.
  Сейчас блокировки применяются симметрично и без учёта конкретного порта и
  направления трафика (`in`/`out`). Нужно:
  - учитывать направление правила;
  - применять блокировку только к тому порту, на котором подключён заблокированный
    узел, а не ко всем узлам через этот роутер;
  - корректно отражать направленность в обоих ячейках матрицы.
- Визуальный «ghost frame» при пошаговом изменении zoom холста: на долю секунды
  между двумя состояниями появляется промежуточный кадр со смещёнными элементами.

## [2.0.0] — 2026-04-11

Крупный релиз: переработка матрицы связности, введение longest-prefix-match
в таблицу маршрутизации, кеширование паспорта безопасности, PDF-экспорт,
выпадающий список VPN-протоколов. Основан на заданиях из **промта 7**.

### Добавлено
- **Матрица связности — учёт VPN.** VPN теперь имеет наивысший приоритет
  (VPN > DIRECT > ROUTED > BLOCKED). Пара «VPN-клиент ↔ VPN-сервер» отображается
  именно как VPN-туннель, а не «прямое соединение». В описание добавляется
  название используемого протокола (`[WireGuard]`, `[OpenVPN]` и т.п.).
- **Матрица связности — маршрутизация через общий роутер.** Метод
  `_check_routed_connections` переписан. Реализован BFS по графу физических
  линков; промежуточными (транзитными) считаются только узлы типа Router /
  Switch / Internet / VirtualizationServer. Теперь АРМ, подключённые к одному
  роутеру, видят друг друга, а подключение Интернета к роутеру даёт связь
  с Интернетом всем подключённым узлам.
- **Паспорт безопасности — экспорт в PDF.** Кнопка «📄 Экспорт в PDF» в окне
  паспорта безопасности. Реализация через `reportlab 4.4.10` (альбомный A4,
  обёрнутые ячейки, регистрация шрифтов Arial / DejaVuSans для кириллицы).
- **Паспорт безопасности — кеширование.** Первое построение паспорта кешируется
  в `node.properties["security_passport_cache"]`, ключ — имя компонента, значение —
  список CVE. При повторном открытии CVE берутся из кеша без обращения к БД.
  При изменении конфигурации узла устаревшие записи удаляются (`_prune_cache`),
  новые — пересчитываются. Кнопка «🔄 Обновить» полностью сбрасывает кеш.
- **Таблица маршрутизации — Longest Prefix Match.** В `Route` добавлены методы
  `prefix_length()`, `normalized_destination()`, `matches_ip()`. Матрица связности
  при проверке маршрутов теперь выбирает наиболее специфичный маршрут (по длине
  префикса), а при равенстве — по минимальной метрике. Default-route (0.0.0.0/0)
  используется только как fallback.
- **VPN — выпадающий список протоколов.** В диалоге настройки VPN добавлены
  комбобоксы выбора протокола для клиента и сервера. Поддерживаемые протоколы:
  WireGuard (по умолчанию, рекомендован), OpenVPN (UDP/TCP), IKEv2/IPSec, IPSec,
  SSTP, L2TP/IPSec *(устарел)*, PPTP *(небезопасен)*, SoftEther, GRE.
- **Контекстное меню зоны — удаление.** Добавлен пункт «🗑 Удалить зону».
- **Бесконечный порт узла Интернет.** В диалоге выбора портов для узла Интернет
  отображается единственный пункт «🌐 Автоматическое подключение»; при создании
  связи автоматически создаётся новый ethernet-порт. Количество подключаемых
  узлов теперь не ограничено.
- **Индикатор zoom.** В правом нижнем углу холста — label с текущим процентом
  масштаба, обновляется при каждом изменении.

### Изменено
- **Фаервол — отмена изменений.** Окно настройки фаервола получает `deepcopy`
  данных. Изменения применяются только при явном нажатии кнопки «Сохранить».
  Закрытие крестиком и кнопка «Отмена» теперь отбрасывают все правки.
  Добавлен хук `protocol("WM_DELETE_WINDOW", _on_cancel)`.
- **Паспорт безопасности — все CVE.** Убраны ограничения `[:5]` во всех пяти
  категориях (порты, USB, аппаратные компоненты, прикладное ПО, периферия).
  Теперь отображаются все найденные уязвимости для каждого компонента.
- **Мировые размеры названий зон.** Шрифт названия зоны теперь вычисляется
  пропорционально её высоте (мировые координаты), а не фиксированно. Крупные
  зоны — более крупные подписи, мелкие — соответственно.
- **Приоритеты статусов связи.** `VPN:5 > DIRECT:4 > ROUTED:2 > BLOCKED:1 > NONE:0`.
- **Валидация маршрута.** `RouteEditDialog.save_route` теперь валидирует
  IP-адреса, маску (CIDR или десятичная), шлюз, метрику. Поле `destination`
  автоматически нормализуется к сетевому адресу (host-биты обнуляются).

### Удалено
- **Ручной ресайз иконок узла.** Убрана возможность drag-resize за уголки,
  удалён пункт «📏 Изменить размер» из ПКМ-меню узла. Иконки теперь всегда
  имеют фиксированный размер (60×60 в мировых координатах).
- **Подсветка выделенной зоны.** Убраны оранжевые уголки и смена цвета фона
  при выделении зоны. Выбранная зона визуально не отличается от остальных.
- **Отображение размера зоны в px.** Убрана плашка «WxH» в правом нижнем
  углу зоны.

### Исправлено
- Удалены все вызовы `_generate_routes_for_node` из `Board.add_link` — именно
  они создавали «рандомно выглядящие» записи в таблице маршрутизации
  (см. v1.2.0, пункт про автогенерацию).

### Known Issues

Выявлены при пользовательском тестировании (промт 8). Планируются к исправлению
в v2.1.0:

- **Таблица маршрутизации.** Визуально таблица и окно создания правила
  практически не изменились по сравнению с предыдущей версией — запланирован
  полный редизайн.
- **Матрица связности и фаервол.** Правила файервола применяются симметрично
  и без учёта конкретного порта. Пример: правило блокировки входящего трафика
  на порту роутера, к которому подключён АРМ1, блокирует и соединение
  роутер → АРМ2 (не должно); а соединение АРМ1 → роутер — наоборот,
  не блокируется, хотя должно.
- **VPN — несовпадающие протоколы.** Соединение VPN показывается как
  установленное даже если клиент и сервер используют разные протоколы.
  В реальности туннель при этом не поднялся бы.
- **Canvas zoom — ghost frame.** При пошаговом изменении zoom на долю секунды
  мелькает промежуточный кадр со смещёнными элементами. Функционально зум
  работает корректно.
- **Паспорт безопасности — поиск CVE.** Сопоставление CVE с компонентами
  использует упрощённую логику «по ключевым словам», что может приводить
  к включению нерелевантных записей. Планируется переинтеграция с nvd.nist.gov.
- **Фаервол — обводка статуса.** Зелёная рамка вокруг строки «Состояние:
  включен/выключен» охватывает всю строку целиком, должна охватывать только
  сам текст статуса.

## [1.2.0] — 2026-04-11

Расширение возможностей холста: zoom и навигация, привязка зон к сетке,
редизайн стартового окна, 90°-маршрутизация соединительных линий.
Основан на заданиях из **промта 6**.

### Добавлено
- **Zoom холста через Ctrl + колесо мыши.** Дискретные уровни масштаба
  `[0.25, 0.33, 0.5, 0.67, 0.75, 1.0, 1.25, 1.5, 2.0, 2.5, 3.0]`. Якорь зума —
  точка под курсором (не «уплывает» при увеличении). Стартовый масштаб 0.75x.
- **Горизонтальная прокрутка через Shift + колесо.** Полный набор навигации:
  - колесо — вертикальная прокрутка;
  - `Shift + колесо` — горизонтальная;
  - `Ctrl + колесо` — масштаб.
- **Расширенный холст.** Размер «мирового» холста — 4000×3000 (вместо 2000×2000),
  с прокруткой через скроллбары.
- **Привязка зон TIM к размерной сетке.** При создании, перетаскивании
  и изменении размеров зон координаты и размеры округляются к кратным шагу сетки
  (как это уже работало для иконок узлов).
- **90°-маршрутизация линий соединений.** Полностью переписан
  `Link.get_bezier_coords`. Линии теперь строятся только из сегментов под 90°:
  - детерминированный выбор сторон выхода/входа по доминирующей оси
    (обеспечивает симметрию для симметричных расстановок узлов);
  - Z-образный путь с минимумом поворотов (0, 2 или 4);
  - `_route_around_obstacles` корректно сдвигает серединный сегмент, сохраняя
    ортогональность соседних сегментов;
  - `_build_detour` добавляет U-образный обход с 4 поворотами, если Z-путь
    не проходит;
  - `_find_clear_mid` подбирает ближайшую свободную координату для сдвига.

### Изменено
- **Стартовое окно (splash).** Перевод в оконный режим (520×220), центрирование
  на экране. Описательные статусы «Загрузка: АРМ: Процессоры…» заменены
  на крупные проценты. Убрана надпись «Analysis-Software-v2». Название
  «Редактор топологии сети» переименовано в
  **«Автоматизированная система построения цифровых карт безопасности»** во всех
  местах (splash, заголовок главного окна, заголовок setup_ui).
- **Значения колонки «сеть назначения»** в таблице маршрутизации. Корень
  проблемы был в методе `_generate_routes_for_node`, который при каждом
  создании линка пересчитывал «прямые маршруты» от IP-адресов портов узла.
  В колонку попадал сетевой адрес (например, `192.168.1.0`), а не IP порта
  (`192.168.1.5`) — отсюда ощущение «рандомных» значений. Хуже того,
  после ручных правок IP эти записи становились устаревшими.

### Удалено
- **Автогенерация маршрутов в таблице маршрутизации.** Удалена кнопка
  «⚙️ Авто-генерация» в `RoutingTableDialog` и метод `auto_generate`.
  Полностью удалён метод `Board._generate_routes_for_node` и его вызовы
  из `Board.add_link`. Таблица маршрутизации теперь содержит только то,
  что пользователь ввёл вручную.

## [1.1.0] — 2026-04-10

Исправления интерфейса, классификации компонентов, рендеринга соединений
и поведения узлов. Основан на заданиях из **промтов 1, 2, 3**. Соответствует
git-коммиту `18e3f5b` — «Fix UI positioning, connectivity matrix, link drawing,
peripheral classification and dialog styling».

### Добавлено
- **Ручной выбор масштаба интерфейса** (инструмент выбора масштаба, как в
  MS Word) как альтернатива авто-масштабированию под разрешение экрана.

### Изменено
- **Окно свойств узла.**
  - Блок «Аппаратура» переименован в **«Аппаратная архитектура»**. Имена
    блоков теперь соответствуют именам вкладок в `NodeCreationDialog`.
  - Убран пустой промежуток перед разделительной синей линией в начале
    блоков компонентов.
- **Унификация стиля фреймов.** Переделан фон диалоговых окон под
  однотонный стиль с минималистичными рамками-выделениями строк параметров.
  Правка применена к: окну настройки VPN, окну создания правил файервола,
  окну редактирования правил файервола, окну настройки маршрутизации,
  окну настройки VM на сервере виртуализации, вкладке «Сеть» во всех узлах
  и виртуальных машинах, окну выбора типа сервера виртуализации.
- **Таблица связей.** Убрана индикация направления (стрелочки) на
  соединительных линиях — трафик двунаправленный, поэтому логика
  «узел А → узел Б» больше не определяет отображение.

### Исправлено
- **Классификация компонентов в окне свойств.** Материнская плата больше
  не попадает в блок «Периферия», а программное обеспечение — в блок
  «Другое». Перепутывание исчезло.
- **Классификация периферийных устройств** (мыши, клавиатуры, принтеры,
  мониторы). Задействованы две отдельные БД DNS (для мышей и клавиатур)
  + основная CVE-БД (для принтеров и мониторов). Классификация работает
  на основе префиксов («Мышь:», «Клавиатура:», «Принтер:», «Монитор:»)
  и ключевых слов.
- **Масштабирование интерфейса под разные разрешения экрана.** Диалоговые
  окна больше не съезжают за экран на мониторах 3200×2000, шрифты
  и иконки адаптируются.
- **Центрирование диалоговых окон.** Все диалоги теперь гарантированно
  появляются по центру экрана независимо от разрешения.
- **Рендеринг линий соединений.**
  - Размер TIM-зоны привязан к размерной сетке (аналогично иконкам узлов).
  - Линии соединений не пересекают иконки узлов — реализован обход.
  - Оптимизация: уменьшено количество поворотов, убраны лишние «обходы
    препятствий», когда они не нужны.
- **Узел «Интернет».** Больше не может быть помещён внутрь TIM-зоны или
  пересекать её границу. При попытке перетащить такой узел внутрь зоны
  он автоматически выталкивается за её пределы.

## [1.0.0] — 2026-04-10

Первый релиз. Соответствует git-коммиту `2e9f15a` — «Initial commit:
Analysis Software v2 with all fixes».

### Базовая функциональность
- Редактор сетевой топологии с холстом на Tkinter/CustomTkinter.
- Модели: `Zone` (TIM-зоны), `Node` (узлы: АРМ, Ноутбук, Маршрутизатор,
  Коммутатор, Сервер, Сервер виртуализации, Интернет), `Link` (соединения:
  Ethernet, PON, Wi-Fi), `NetworkPort`, `VirtualMachine`, `Route`,
  `FirewallRule`, `FirewallManager`.
- Диалоги: создания/редактирования узлов, создания зон, создания
  соединений (выбор портов), настройки VPN, настройки фаервола,
  таблицы маршрутизации, управления виртуальными машинами, свойств узлов.
- Паспорт безопасности узла на основе локальной CVE-базы.
- Матрица сетевой связности с поддержкой прямых соединений, VPN,
  маршрутизации и блокировок файрволом.
- Загрузка баз данных при старте: CVE, периферия (мыши, клавиатуры).
